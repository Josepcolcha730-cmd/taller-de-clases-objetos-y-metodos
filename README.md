# Programación II - Clases y objetos en Java

Resolución de los ejercicios 3.12, 3.13, 3.14, 3.16 y 3.17.

**Integrantes:** Geovanny Silva y Josep Colcha.  
**Docente:** Bernarda Sandoval.  
**NRC:** 5434.

| Carpeta | Ejercicio | Entrada |
|---|---|---|
| 3.12-factura | Factura | Scanner |
| 3.13-empleado | Empleado | Scanner |
| 3.14-fecha | Fecha | JOptionPane |
| 3.16-frecuencias-cardiacas | Frecuencias cardíacas | JOptionPane |
| 3.17-perfil-medico | Perfil médico | JOptionPane |

Cada carpeta es independiente. Compila y ejecuta desde la carpeta del ejercicio;
no compiles todos los directorios juntos porque contienen utilidades con el mismo nombre.
Se necesitan JDK 8 o posterior y un escritorio gráfico para las ventanas.

Se utilizan atributos privados, constructores, getters y setters, separación entre
modelo e interfaz y reutilización de cálculos en PerfilMedico. Entrada centraliza la
validación y lectura en cada ejercicio. Las fórmulas de salud son las del enunciado
académico. Los datos de prueba son ficticios.

La consigna solicita ventanas en la mitad de los ejercicios; para cinco ejercicios
se distribuyen tres con ventanas y dos con Scanner.
