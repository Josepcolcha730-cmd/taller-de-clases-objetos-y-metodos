# Ejercicio 3.14 fecha

Clase principal del modelo: `Fecha`. Aplicacion de prueba: `PruebaFecha`.

Abre una terminal en esta carpeta. Requiere JDK 8 o posterior.

```shell
javac -encoding UTF-8 *.java
java PruebaFecha
```

Los archivos auxiliares se incluyen para ejecutar este ejercicio de forma independiente.
Los valores de los ejemplos son ficticios.
